What are Secure Notes?

Secure Notes is for private text that does not fit neatly into a saved login. You might use it for important instructions, license details, Wi-Fi information or other personal reminders you choose to keep in your vault.

Organize notes so you can find them

Add a title and note, choose a category, and use tags to group related entries. Pin a note you access often. Search helps you find a saved entry later. Secure Notes is available in Security Vault on Android and the web.

How to use Secure Notes

  1. Unlock your vault and open Secure Notes.
  2. Create a note with a title that makes sense to you.
  3. Add the text, then choose a category or tags if they will help you find it.
  4. Review, edit or delete the note when the information changes.

How are notes protected?

Note content is encrypted on the server and shown after authorized vault access. Security Vault manages the encryption key on its server; Secure Notes is not currently end-to-end encrypted. See the Security page for details.

If you have a collection of backup codes, the dedicated Security Codes area may be easier to use. For images, PDFs or text files, see Secure Files. Return to all feature guides.
