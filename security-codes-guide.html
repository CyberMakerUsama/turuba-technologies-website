What are Security Codes?

Backup and recovery codes are often provided by another service when you turn on two-factor authentication. They can help you regain access if you lose your authenticator. Security Vault's Security Codes area gives you a place to save and organize codes you have received.

What can you save?

Create a record for the account or service the codes belong to, add the individual codes, and keep a note that helps you recognize them later. Security Vault stores the codes you enter; it does not create replacement codes for another service or check whether a code is still valid.

How to use Security Codes

  1. Get the backup or recovery codes from the service that issued them.
  2. Open Security Codes in your vault and add a clearly named record.
  3. Save the codes exactly as issued. Keep track of codes you have already used, because many services make each code valid only once.
  4. If the other service gives you a new set, update your saved record.

How are they protected?

Saved code content is encrypted on Security Vault's server and is available after authorized vault access. The service holds the encryption key, so this is server-side encryption rather than end-to-end encryption. Read the security overview for the exact protections and limitations.

Security Codes and account 2FA are different

Security Vault's optional authenticator-based two-factor authentication helps protect your Security Vault account. The Security Codes area is for codes that you choose to save, including codes from other accounts. Saving a code here does not turn on 2FA for that service.
