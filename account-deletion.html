Security Vault Account Deletion

Developer: TURUBA Technologies

Last updated: September 25, 2026

This page is for users of the Security Vault mobile application and web service. You can use this page to request deletion of your Security Vault account and the data associated with it.

How to request account deletion

  1. Send the request from the email address registered with your Security Vault account.
  2. Use the subject line Security Vault Account Deletion Request.
  3. Include the registered email address or username so we can identify the account.
  4. We will verify the request and process the deletion.

Request account deletion

For your security, do not send your password, master password, recovery codes, vault tokens, API tokens, encryption keys, or other secret credentials in the request.

What data is deleted?

The deletion request covers the Security Vault account and associated user data that the service is able to delete, including account/profile information and user-created vault data such as stored passwords, secure files, and security codes, subject to any applicable legal or security retention requirements.

Data that may be retained

A limited amount of information may need to be retained where required for legal compliance, security, fraud prevention, dispute resolution, or legitimate backup/recovery requirements. Where retention is necessary, the information will be retained only for the period reasonably required for that purpose and handled according to our Privacy Policy.

Need help?

If you cannot access your registered email address or need help with the deletion request, contact support@turubatechnologies.com.
