Security Vault Account Deletion

Last updated: September 24, 2026

Security Vault users can request deletion of their account and associated data. The mobile application also provides an in-app account deletion path.

Request deletion

Send an email from the account's registered email address to:

Request account deletion

Use the subject Security Vault Account Deletion Request. Include the registered email address or username so that we can identify the account. Do not send your password, master password, recovery codes, vault tokens, API tokens, or encryption keys.

What happens after a request

We will verify the request and process deletion of the account and associated user data that the service is able to delete. Certain records may be retained where necessary for security, fraud prevention, backups, legal obligations, dispute resolution, or other lawful purposes. Where data is retained, it will be kept only as reasonably necessary for that purpose.
