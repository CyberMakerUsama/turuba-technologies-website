What is a password manager?

A password manager is an application that stores login credentials so you can organize different passwords for different accounts. Security Vault is TURUBA Technologies’ password manager, with additional tools for secure files, security codes and account protection.

What does a password manager help you do?

Start with the accounts you already use: email, shopping, work tools and other services. A vault gives each saved login a place, instead of leaving you to remember which password belongs to which account. When choosing a product, check how credentials are saved, edited and accessed on the devices you use.

A password generator complements this storage. It helps create a new credential; the manager keeps the saved record organized. Generating a password does not automatically change the password on another website.

What should you check before choosing a password manager?

  • Account protection: look at the authentication options and the controls available if a device is lost.
  • Recovery: understand how account recovery works before you rely on a vault for important credentials.
  • Security information: read the provider’s description of its data protection and its limitations.
  • Practical fit: check device support, access requirements and any features you need. Do not assume every password manager has the same tools.
  • Support and privacy: find the support channel, privacy policy and account deletion process.

What is included in Security Vault?

Security Vault includes saved-password management, a password generator, encrypted secure-file storage and protected security-code storage. Its account tools include two-factor authentication, recovery controls, vault locking, active-session management and security activity. Biometric unlock is available on supported mobile devices.

See the Security Vault password manager overview for features and mobile app screens. Review the security information and privacy policy before deciding whether the product fits your needs.

How to get started

  1. Open Security Vault from the official product page and create your account.
  2. Complete the available account verification and review your recovery options.
  3. Save a login record and check that you can find it again.
  4. Use the password generator when setting or changing credentials on the relevant service.
  5. Review the account security controls and enable the protections appropriate for your account.

For general password guidance, CISA recommends long, random and unique passwords. Read its password safety tip sheet. For product help, contact Security Vault support.
