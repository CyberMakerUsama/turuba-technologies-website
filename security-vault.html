SECURITY AND PRIVACY

Understand the protections behind your vault.

Account and master passwords are stored as bcrypt hashes. Saved passwords, security codes, notes, money entries and file contents use server-side Fernet encryption. Fernet uses AES-128 for encryption and HMAC-SHA-256 to detect changes to encrypted data. Production web and API communication uses HTTPS.

The service holds the encryption key and decrypts vault content when you access it. This is not end-to-end or zero-knowledge encryption; someone with access to both stored data and the server key could technically read it. These controls reduce risk but cannot guarantee absolute security.

Read the Security page for current security controls and responsible disclosure information, or review the Privacy Policy to learn how information is handled.

COMMON QUESTIONS

Security Vault FAQs

Product details and ways to get help.

Where do I log in or sign up for Security Vault?

Use the official Security Vault login page to access an existing account. New users can sign up for Security Vault.

What is Security Vault?

Security Vault is a password and secure-file manager from TURUBA Technologies. It also includes password generation, protected security-code storage, account security controls, Secure Notes and Money Ledger on Android and the web.

What can I keep in Secure Notes?

Secure Notes lets you keep private notes on Android or the web, organize them with categories and tags, and pin important entries for easy access.

What does Money Ledger do?

Money Ledger helps you keep a personal record of money lent, borrowed and repaid on Android or the web. It records entries; it does not send or receive payments.

Can I preview secure files without downloading them?

Yes. Supported images, PDFs and text files can be previewed in the app without choosing a separate download. Other files can be downloaded when you choose.

Can TURUBA Technologies decrypt my vault data?

Vault content is encrypted on the server, but the service holds the decryption key so it can show content after you unlock your vault. This is not a zero-knowledge service. See our Security page for details.

Can Security Vault generate passwords?

Yes. Security Vault includes a password generator and related security tools.

Can I use Security Vault online?

Yes. The Security Vault web app is available at vps.turubatechnologies.com.

How can I learn about its security practices?

Visit the Security page for a summary of current controls and instructions for reporting a potential vulnerability.

Where can I get help with Security Vault?

Visit Security Vault Support or email support@turubatechnologies.com. Do not send passwords, recovery codes, or encryption keys by email.
