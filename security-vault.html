SECURITY AND PRIVACY

Understand the protections behind your vault.

Security Vault uses password hashing and encryption mechanisms for vault data and files, and production web/API communication uses HTTPS. Security controls can reduce risk, but no online service can promise absolute security.

Read the Security page for current security controls and responsible disclosure information, or review the Privacy Policy to learn how information is handled.

COMMON QUESTIONS

Security Vault FAQs

Product details and ways to get help.

What is Security Vault?

Security Vault is an online password and secure-file manager from TURUBA Technologies. It also includes password generation, protected security-code storage, and account security controls.

Can Security Vault generate passwords?

Yes. Security Vault includes a password generator and related security tools.

Can I use Security Vault online?

Yes. The Security Vault web app is available at vps.turubatechnologies.com.

How can I learn about its security practices?

Visit the Security page for a summary of current controls and instructions for reporting a potential vulnerability.

Where can I get help with Security Vault?

Visit Security Vault Support or email support@turubatechnologies.com. Do not send passwords, recovery codes, or encryption keys by email.
