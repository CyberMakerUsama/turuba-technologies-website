What are Secure Files?

Secure Files is the file area of Security Vault. You can upload sensitive files to encrypted server storage, access them through your vault, and remove them when you no longer need them.

What can you do with a file?

  • Store it: upload a file within the current file and storage limits.
  • Preview it: view supported images, PDFs and text files in the app without choosing a separate download.
  • Download it: save your own copy when you need one.
  • Delete it: remove a file from your account when you no longer want it stored.

Preview support depends on file format and size. A preview sends the decrypted content to your app or browser for display; it is not a promise that the content never reaches your device.

How are files protected?

File contents are encrypted before being stored on the server. After authorized access, the server decrypts a file for preview or download. The server holds the encryption key, so Secure Files is not currently end-to-end or zero-knowledge encrypted. Learn more on the Security page.

A simple workflow

  1. Unlock your vault and open Secure Files.
  2. Upload the file you want to keep and check that it appears in your list.
  3. Use Preview for a supported file, or Download when you want a separate copy.
  4. Delete files you no longer need to keep in the vault.
