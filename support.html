Security Vault Support

For help with Security Vault, account access, recovery, security questions, or product feedback, contact our support team. See the Security Vault product overview for features.

Contact support

support@turubatechnologies.com

Before contacting support

  • Do not send your password or master password.
  • Do not send recovery codes, API tokens, vault tokens, or encryption keys.
  • Describe the issue and include non-sensitive error details where possible.

Account deletion

You can request account and associated data deletion from the Account Deletion page.

Security vulnerabilities

For responsible disclosure, email support@turubatechnologies.com and clearly identify that the message is a security report.
