How to use a password generator

A password generator creates a candidate password using the settings you choose. Security Vault includes a generator in its app, alongside tools for managing saved credentials. This guide explains the options shown in the mobile app and how generation fits into updating an account.

Choose settings that fit the account

The Security Vault mobile generator provides a password-length control and options for uppercase letters, lowercase letters, numbers and symbols. Check the requirements on the service where you plan to use the password, then select compatible options in the generator.

Length and uniqueness matter. CISA’s password guidance recommends at least 16 characters, randomness and a different password for each account. Follow the destination service’s supported length and character rules.

Generate, apply and save

  1. Open the Generator: find it in the Security Vault mobile app.
  2. Set the length and character options: match the requirements of the account you are updating.
  3. Generate a password: use the app’s generation control and copy the result when you are ready to use it.
  4. Apply it on the relevant service: complete that service’s signup or change-password process. Generating a value in Security Vault alone does not update that account.
  5. Save the matching record: add or update the credential in your vault so the saved entry matches the password accepted by the service.

Password generator or password manager?

These tools perform different jobs. A generator creates a value; a manager helps you store and organize login records. Security Vault combines both capabilities. It also provides separate areas for secure files and security codes.

Read what a password manager does if you are choosing a product for the first time.

Common questions

Does the generator change my existing passwords?

No. You must complete the password change on the account’s own website or app and update your saved vault entry accordingly.

Can I generate a password from this guide?

This page explains the workflow. The generator is part of the Security Vault app; use the official product page to explore the app and its available access options.

What if a website rejects the generated password?

Check its length and character requirements, adjust the generator settings and try a new value. Contact the service if its rules are unclear. For issues with the vault, use Security Vault support.
