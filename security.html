Security

Last updated: September 17, 2026

Security Vault is developed with security controls including encrypted credential/file handling, password hashing, authentication controls, two-factor authentication, session controls, vault auto-lock, security activity/alerts, and rate limiting.

Responsible Disclosure

If you identify a potential security vulnerability, please report it to hello@turubatechnologies.com. Please provide reproducible details and avoid accessing, changing, or deleting other users' data.

Important

Security measures reduce risk but cannot guarantee that an internet-connected service will never be compromised. Users should use strong unique credentials and keep recovery information secure.
